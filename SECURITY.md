# Security Policy

Identiqa builds security products, so we hold ourselves to the standard we sell. If you found something we missed, we want to hear about it, and we pay for it.

## Report a vulnerability

Use our security portal: **[security.identiqa.com/report](https://security.identiqa.com/report)**

Please don't open a public issue or pull request for a security problem.

We acknowledge every report within one business day, and you can follow it under [Status](https://security.identiqa.com/status).

## Scope, rewards, and safe harbor

Our vulnerability disclosure program lives on the portal, and it is the binding version:

- [Program, scope, and rewards](https://security.identiqa.com/): USD 100 to 10,000 per valid finding, by severity
- [Terms](https://security.identiqa.com/terms): review process, payout conditions, and safe harbor for good-faith research

If you're unsure whether a finding in one of our repositories is in scope, report it and say so.
